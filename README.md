# پروژه آمار

## بررسی الگوی BMI در گروه‌های سنی مختلف با استفاده از داده‌های NHANES 2021–2023

این مخزن مربوط به پروژه درس آمار است. تحلیل‌ها به‌صورت مرحله‌ای، از شناخت داده و آمار توصیفی تا استنباط آماری و مدل‌سازی، انجام می‌شوند.

## داده‌ها و منبع

داده‌های فاز اول از دو فایل رسمی NHANES تهیه شده‌اند:

- `DEMO_L.xpt` — اطلاعات جمعیت‌شناختی
- `BMX_L.xpt` — اندازه‌گیری‌های بدنی

این فایل‌ها با استفاده از شناسه مشترک `SEQN` ادغام شده‌اند.

**منبع:** CDC / National Center for Health Statistics — [NHANES 2021–2023](https://www.cdc.gov/nchs/nhanes/)

داده‌های خام و پردازش‌شده در GitHub قرار نمی‌گیرند. روش دریافت و بازسازی آن‌ها در `data/README.md` مستند می‌شود.

## سؤال آماری اصلی

در افراد بزرگسال ۲۰ ساله و بالاتر، BMI در گروه‌های سنی مختلف چه الگویی دارد و این الگو چه تفاوتی بین زنان و مردان نشان می‌دهد؟

گروه‌های سنی مورد بررسی:

- ۲۰–۳۹ سال
- ۴۰–۵۹ سال
- ۶۰ سال و بالاتر

مقایسه بر اساس جنس نیز به‌عنوان بخش تکمیلی تحلیل‌های توصیفی انجام می‌شود.

## نتایج اولیه فاز اول

میانگین BMI در افراد ۲۰ ساله و بالاتر، به تفکیک گروه سنی:

| گروه سنی | میانگین BMI |
|---|---:|
| ۲۰–۳۹ | 29.41 |
| ۴۰–۵۹ | 30.70 |
| ۶۰+ | 29.51 |

در داده‌های مشاهده‌شده، میانگین BMI ابتدا افزایش و سپس کاهش می‌یابد. این یافته در فاز اول صرفاً توصیفی است.

## وزن‌های نمونه‌گیری

با توجه به طرح نمونه‌گیری پیچیده NHANES، وزن معاینات (`WTMEC2YR`) و متغیرهای طراحی نمونه‌گیری (`SDMVSTRA` و `SDMVPSU`) در تحلیل‌ها مورد توجه قرار می‌گیرند.

مقایسه اولیه میانگین BMI:

| نوع محاسبه | میانگین BMI |
|---|---:|
| بدون وزن | 27.247 |
| وزن‌دار | 27.645 |

این مقایسه اولیه است و به‌تنهایی جایگزین تحلیل کامل با درنظرگرفتن طرح نمونه‌گیری پیچیده نیست.

## محیط اجرا و وابستگی‌ها

پروژه با Python و کتابخانه‌هایی مانند `pandas`، `matplotlib` و `jupyter` انجام می‌شود.

برای ساخت محیط مجازی و نصب وابستگی‌ها:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

سپس Notebookهای پروژه را می‌توان با Jupyter اجرا کرد. پوشه `.venv/` در Git ثبت نمی‌شود.
